# FLUX CORE

AI-powered code generation and software engineering platform powered by MiMo V2.5 + Hermes Agent.

## Architecture
- **Architect** — System design & task decomposition
- **Coder** — Production-ready code with full test coverage
- **Reviewer** — Security audits & coding standards enforcement
- **Deployer** — CI/CD pipelines & infrastructure provisioning

## Tech Stack
- MiMo V2.5 (chain-of-thought code reasoning)
- Hermes Agent (orchestration layer)
- Claude series (language understanding)
